# main 71a83062e9f: docs/api/core/network.md, the rule-version record
879:The cache also records, under `cache_rule_version`, the version of the sensitive-key rule (`ApiLoggingInterceptor.sensitiveKeyRuleVersion`) its entries were written under. When a build changes the rule - a new secret name makes some URLs secret queries, which the cache then never reads or evicts - the first request drops every cached entry, since a hashed key cannot say which URL it was. Entries with no recorded version (written by a build before this record) are dropped the same way. A purge that fails is retried on the next request. `clearCache()` removes the record with the entries. Bump `sensitiveKeyRuleVersion` with every change to the key sets; `cache_rule_version_test.dart` fails until you do.
