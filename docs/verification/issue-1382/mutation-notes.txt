How the mutation logs were produced (issue 1382, PR 1407)

Both logs come from the PR branch before merge. The only difference from the
merged test is the lint fix that dropped a raw-string prefix ('...' in place
of r'...'), which leaves the regex unchanged.

To mimic ubuntu-latest, which has no xmllint, the two xmllint tests were made
to skip locally by temporarily changing _has('xmllint') to
_has('xmllint-absent-as-on-ci'). That edit was reverted and never committed.

  "unescaped &" and one on "unescaped <". Without the new tests the issue
  records +5 ~2: All tests passed!
fixed-no-xmllint.log: same skip, escaping restored. +7 ~2: All tests passed!

Removing one escape at a time, rerun on merged main 08a89201cd2 with xmllint
still skipped, logged in mutation-drop-{amp,lt,quot}.log:
  drop &amp;  -> both new tests fail (unescaped &)
  drop &lt;   -> both new tests fail (unescaped <)
