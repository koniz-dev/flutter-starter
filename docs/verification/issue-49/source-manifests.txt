    fix(android): declare INTERNET permission in the main source set (#66)
    
    `android.permission.INTERNET` was declared only in the debug and profile
    source sets (stock `flutter create` layout), so the merged release manifest
    carried no network permission and every request in a release build failed
    with `SocketException: ... EPERM (Operation not permitted)`.
    
    Moving the declaration into `android/app/src/main/AndroidManifest.xml` puts
    it in all three variants. The debug and profile manifests are left alone,
    and no other permission is added.
    
    Refs koniz-dev/flutter-starter#49
    
    Co-authored-by: Claude Opus 5 (1M context) <noreply@anthropic.com>
