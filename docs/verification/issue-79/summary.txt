Criterion -> artifact
---------------------

   `- .env` was suggested, that an asset declaration applies to every build

   it is fetchable at /assets/.env

     -> criterion-1-2-configuration-guide.txt

     -> criterion-3-env-example.txt

     -> criterion-4-guard.log

5. No real secret added to the tree; .env stays gitignored
     -> criterion-5-no-secrets.txt

Not verified here (unchanged from the filing security review): no release APK,
IPA or web bundle was built to observe the extraction first-hand. This
environment cannot produce signed release artifacts. The claim rests on
Flutter's asset model having no build-mode scoping, which is documented
behaviour. Nothing in the fix depends on that observation: every criterion
above is about what the documentation says and what the guard does, and each
one was driven directly.
