--- network.md, Realtime Client
352:- `RawWebSocketClientImpl`: Concrete class powered by the `web_socket_channel` package. Its handshake follows the same pinning policy as `ApiClient`: when pinning is in effect it connects through the pinned `HttpClient` from `SslPinning.createHttpClient()`, so a `wss://` server whose certificate the fingerprints do not name is refused. Pass `sslPinning:` to use a different policy.
