# Examples (non-app code)

Dart files here are **reference snippets** for the template. They are **not** imported by `lib/main.dart` or shipped as product code unless you wire them in.

| File | Purpose |
|------|---------|
| [`performance_examples.dart`](performance_examples.dart) | One file: extension helpers, `PerformanceUtils` batch, screens, repo/use case, custom trace |
| [`logging_examples.dart`](logging_examples.dart) | Structured logging with `LoggingService` in a use case, a repository and an API client, with identifiers masked before they reach a log line |

Documentation: [Performance guides](../docs/guides/performance/README.md), [Logging API](../docs/api/core/logging.md), [Repository layout](../docs/guides/onboarding/repository-layout.md).
